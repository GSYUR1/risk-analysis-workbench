# 风控策略分析 Agent

工作台定位：优先使用用户明确指定的工作台根路径。Skill保留在仓库的 `skills/risk-analysis-agent/` 时，可将Skill目录上两级作为候选根，核实存在 `AGENTS.md`、`工作约定/README.md` 和 `工具/workbench.py` 后使用。单独安装且未明确工作台位置时先询问用户，不猜测个人路径；CLI可使用 `--root` 显式指定，参数放在子命令之前。当前打开的业务项目是分析现场；不依赖旧对话记忆猜测规则。工作台总领文件、工具目录和阶段路由分别见根 `AGENTS.md`、`README.md`、`工作约定/README.md`、`工作约定/工具调用与分析输出.md` 和 `工具/README.md`。

## 强制启动阅读

每次使用必须显式读取工作台 `AGENTS.md`、`工作约定/README.md`、`工作约定/操作手册.md`、`工作约定/安全与审批规范.md`。随后按 `工作约定/README.md` 的“必读矩阵”加载本阶段的运行环境、数据口径、工具、报告、归档或知识规范；缺少必读文件先报告，不创建空工作台冒充原档案。

## 执行路径

- 按操作手册识别已有 `analysis_id` 和事项路径；继续同一业务目标只关联窗口，不重复立项。
- 方案和业务定义读取国家数据口径及相关key，不在Skill复制国家默认值、执行参数或文件布局。
- 进入取数、指标或报告阶段时，读取 `工作约定/工具调用与分析输出.md` 和 `工具/README.md`，按 `odps-query -> ph_data_analysis -> 数据口径定义 -> 自定义逻辑` 的优先级工作；已有函数存在时不自行重写指标名称或公式。
- 菲律宾指标和透视优先使用 `工具/ph_data_analysis.py`；标准指标和交叉表导出使用 `工具/excel_export.py` 的格式化导出函数；复杂模板化工作簿按必读矩阵读取 `spreadsheets` Skill，并使用其 `@oai/artifact-tool` 工作流。
- `spreadsheets` 是平台预装能力，不是本Skill新增的工作台脚本；它负责复杂工作簿结构和视觉校验，不替代业务口径或指标计算。
- 外部执行、回传和审批遵守安全规范；工具开关不等于本次授权。
- 归档正文必须满足分析归档规范。历史案例不自动晋升知识，正式知识变更单独审核。

## 新客授信宽表 → 透视聚合底表

用户要求“透视表底表的底表”“按维度汇总宽表”“select维度、指标再group by”时，读取工作台 `工作约定/数据口径/ph/透视聚合底表.md` 和 `pivot_base_profile.json`，调用 `工具/pivot_base_sql.py` 生成SQL及关联检查SQL；这不是直接制作Excel透视表。

字段清单以该profile为唯一入口：默认9个维度，`cre_cnt`起的140个指标保持用户给定名称和顺序；维度按任务增减，指标不自行缩减。区分已有指标列的宽表与原始明细宽表，不能把两类聚合公式混用。补维度时先核对关联键、唯一性和时点，防止扩行。全授信漏斗任务不套用仅成交筛选。仅要求生成SQL时不执行；真实取数仍经 `odps-query` 并遵守审批规范。

## 文档治理

规则修改先查工作约定职责表，优先修改已有权威文件；工具职责只在 `工具/README.md` 维护，工具调用顺序只在 `工作约定/工具调用与分析输出.md` 维护。业务和工作台经验留在工作台，不自动改全局memory或其他Skill。

本Skill只负责路由；命令、目录、安全细则、业务定义和Excel展示规则均以工作台对应权威文档为准，不维护第二套副本。
