# 筛选规则整理

本文件是待办与验收结构，不是已批准的筛选规则。2026-10-28对现行工作约定、知识库、分析模板的定向检索，尚未定位到完整评级×月份lift标准；不据此推断历史事项没有规则。

## 逐条迁入要求

| 内容 | 必须核对 |
|---|---|
| 来源 | 原事项、原文或文件引用、确认记录；不得仅凭对话印象 |
| 适用范围 | 国家、产品、客群、特征类型和有效日期 |
| 指标 | 风险点、分子分母、成熟条件、lift比较基准的口径key |
| 判定 | 正负方向、阈值、最低成熟样本量、月份数、连续性 |
| 组合 | 评级之间和月份之间的AND/OR、指定评级还是所有评级 |
| 缺失 | 缺月份、未成熟、零分母、低样本的处理 |
| 状态 | 事项特例、待审核候选、已确认可复用规则、被替代版本 |

实现后输出应区分“满足条件 / 不满足条件 / 证据不足”，并保留逐条件结果与原因。缺数据不能默认通过，也不应伪装成已证明无效。

指标定义只引用数据口径；通用判定算法写入方法；实际阈值在经确认的规则配置维护一份；经验知识只引用规则ID及证据。候选规则确认前不创建带默认阈值的可执行配置。

特征分析入选不等于线上决策规则已批准或策略收益已验证。
