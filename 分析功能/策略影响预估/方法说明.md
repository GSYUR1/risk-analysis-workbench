# 额度调整影响预估方法 v1

本文件维护分析方法，不是国家指标定义。默认弹性和开关只在同目录规则JSON维护；它们是用户指定的可调整情景假设，不是已校准因果关系。风险点、分母、成熟度和币种引用实际事项与国家数据口径。

## 1. 基准与适用范围

输入是一组互斥叶子分组，按件数而非未经验证的去重人数计量。汇总/小计行先移除，不跨组累加非互斥去重人数。当前实现不对原生Excel透视布局作自动推断；明确平面范围后只读已有值，含公式的输入需先由来源方完成重算。

平均额度是调整前实际平均额度，不能把未应用系数的原始额度再当作已应用后的额度。授信通过件数、动支件数、成交件数需同样本同观察窗。不能仅用成交样本反推动支率。

固定假设：授信通过规模不变、动支后成交成功率不变、同组新增成交构成与原组相同、额度与成交件均同比例变化。成熟分母推算还要求成熟比例/期限结构不变。组合策略重叠命中、拒绝策略、价格/期限调整、真实因果收益不在本模型范围。

## 2. 逐组计算

定义额度倍数factor：新增系数=coefficient；旧新迁移=new_coefficient/old_coefficient；取消已生效系数=1/coefficient。所有系数须正且有限；零额度/拒绝策略须使用另行定义的方法。

```text
额度变化率 = factor - 1
新平均额度 = 原平均额度 × factor
原成交件均 = 原成交金额 / 原成交件数
新成交件均 = 原成交件均 × factor
新风险率 = 原风险率 × (1 + 风险弹性 × 额度变化率)

原动支率 = 原动支件数 / 授信通过件数
关闭动支影响：新动支率 = 原动支率；动支变化倍数 = 1
开启动支影响：未封顶新动支率 = 原动支率 × (1 + 动支弹性 × 额度变化率)
新动支率 = min(未封顶新动支率, 1)
动支变化倍数 = 新动支率 / 原动支率
新成交件数 = 原成交件数 × 动支变化倍数
新成交金额 = 原成交金额 × factor × 动支变化倍数
```

动支率封顶后必须使用实际倍数，报告披露封顶组数。原动支率为零且成交为零时线性模型仍为零，倍数记1，不推断凭空新增成交。零成交件数时件均为NA、成交金额保持零。预估件数是期望值，可以为小数，不提前取整。

风险涨幅是相对变化而不是百分点；风险率超出[0,1]或预估动支率小于0时拒绝该情景，不静默修正。默认假设下额度增10%时风险相对增5%，启用动支后成交件数增2%、成交金额增12.2%（未封顶情况下）。该算例不替代规则配置。

## 3. 风险汇总

`mature`：原分母为该风险点成熟金额/件数。金额风险的新分母=原分母×factor×动支倍数；件数风险的新分母=原分母×动支倍数。新分子=新风险率×新分母。各汇总层级分别SUM分子/SUM分母，不能对率取平均。

`unavailable`：只有组内风险率，仍展示各组风险预估，不输出整体风险率。

`transaction_proxy`：仅金额风险可显式使用成交金额作权重。报表和配置持续标注此近似，不称为原成熟风险口径，也不作为静默缺失回退。

分母为0表示已知未成熟，组风险展示NA，汇总时该组贡献零分子/零分母；所有组均未成熟时整体为NA。分母缺失不同于零，只要目标汇总有缺失权重，其风险汇总为NA，不把有分母子集冒充整体。正分母却缺风险率直接报错。

## 4. 其他汇总

- 平均额度按授信通过件数加权；成交件均按总成交金额/总成交件数重算。
- 动支率按总动支件数/总授信通过件数重算；关闭动支且没提供动支字段时动支率保持NA。
- 相对变化为新/旧-1；旧值为0时相对变化NA，不输出无穷。
- 风险百分点变化=(新率-旧率)×100，与相对变化分列。
- 多个汇总层级从同一叶子底表独立计算，不相互加总，不混加All。

## 5. 复现与限制

每次运行固定原配置、解析后参数、规则ID/版本/哈希、方法代码哈希、输入来源和定义文件哈希。默认规则变更不修改历史报告；输出存在时拒绝覆盖。

Excel初始公式缓存来自Python快照，回读比对不等于Excel引擎重算。Excel改参数仍是情景探索；修改输入结构、口径、权重模式须重跑Python，校验组数等快照不随手改数据动态更新。
