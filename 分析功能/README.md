# 分析功能导航

从业务问题进入，不从脚本名猜功能。各功能的 `capability.json` 维护机器清单；`工具/capability_catalog.py` 校验引用并生成派生索引，不扫描历史全文。

| 我要做什么 | 功能入口 | 当前边界 |
|---|---|---|
| 找新变量、生成候选特征 | [特征挖掘](特征挖掘/README.md) | 待内置；本轮不引用、接入或复制外部特征挖掘Skill |
| 分析区分度、稳定性、评级×月份表现 | [特征分析](特征分析/README.md) | 已有指标和交叉表可用；自动筛选标准尚待逐条确认 |
| 估算额度调整后的规模与风险 | [策略影响预估](策略影响预估/README.md) | 内置额度调整情景计算；仅合成数据离线验证，不是收益验证 |
| 组织一次大版本升级 | [策略版本迭代](策略版本迭代/README.md) | 专题流程指引；非自动决策或线上发布工具 |

## 人和AI共用的执行顺序

1. 读取工作台AGENTS及工作约定必读矩阵，遵守统一生命周期与安全边界。
2. 根据目标选择本页功能；读取其入口、机器清单和实际所需方法/规则。
3. 按国家、产品和指标key加载数据口径，不复制第二套定义。
4. 在当前事项固定输入、规则版本、参数及例外；调用已有工具，不为新功能重复取数或另造导出器。
5. 保存结果、来源引用及哈希，按事项验收。功能通过离线测试不代表真实业务验证或已获远程执行授权。

## 归属与唯一权威

| 内容 | 唯一维护位置 |
|---|---|
| 所有功能共用的生命周期、安全、导出要求 | 工作约定 |
| 指标、样本、分母、成熟度、来源表 | 工作约定/数据口径 |
| 功能方法、适用边界、判断逻辑 | 本功能方法说明 |
| 可执行阈值与默认假设 | 本功能规则配置；文档解释含义，不重复维护默认值 |
| 功能专属空白输入 | 本功能模板；通用立项和归档模板仍在分析模板 |
| 代码实现与离线测试 | 工具；不在功能目录复制实现 |
| 本次实际参数、输入与输出 | 业务项目的现有risk-analysis事项 |
| 经验结论、支持证据与限制 | 知识库；引用规则ID，不复制可执行规则 |

`capability.json` 使用标准库可读取的JSON，避免仅为目录引入YAML依赖。清单只维护ID、状态、入口和依赖等机器元数据，不复制方法正文。索引是生成物，不能手改或作为执行授权。

## 新增功能的最小要求

- 先明确是否为独立能力还是组合已有能力的专题流程；复用统一事项管理。
- 至少提供README和capability.json；确有内容时才增加方法、规则、模板、合成示例，不预建空产物目录。
- 状态区分 `planned`、`partial`、`available`、`workflow`；只描述实际实现，验证证据单列。
- 将代码登记到工具职责表，将新文件登记到发布清单；更新生成索引并检查失效引用。
- 规则变更保留来源、范围、版本与替代关系；历史事项固定原参数，不随默认规则自动重算。
- 后续特征挖掘优先内置到本工作台，迁入前核对授权、依赖和运行边界；暂不通过用户级Skill路径占位。
