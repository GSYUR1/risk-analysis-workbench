# 策略版本迭代

状态：专题流程指引，不是自动执行器。不因目录存在就视为已实现策略搜索、上线或收益验证。

## 推荐阶段

1. 明确版本目标、基准策略、客群、主要问题与约束。
2. 根据问题选择现有特征分析；需要新特征时记录挖掘需求，当前挖掘内置尚未完成。
3. 形成候选策略，记录规则变化与命中样本，处理重叠命中，不能直接叠加各条策略收益。
4. 对适用的额度调整调用策略影响预估；其他策略类型不能套额度弹性公式。
5. 比较候选方案与限制，制定适用的验证安排，形成版本决策材料。
6. 按现有流程验收与复盘；上线、远程执行、归档和知识晋升各守授权边界。

## 组织方式

同一版本目标继续同一analysis_id，阶段写入plan.json，运行分别留run_id；不因窗口或阶段新增第二套事项。若确属独立目标再按操作手册立项。

复用各功能的入口、规则和工具，不复制算法；保存各阶段所用版本与参数。日常单项分析可以直接调用对应功能，无须强行走完整版本流程。
