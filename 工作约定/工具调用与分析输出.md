# 工具调用与分析输出

本文件只维护分析任务拿到后应调用什么工具、按什么优先级生成指标和报告、如何做通用与条件验收。脚本的具体职责见 `工具/README.md`；国家业务定义见 `工作约定/数据口径/<国家>/`；事项生命周期见《操作手册》。

## 一、调用总原则

1. **取数和ODPS**：使用 `odps-query` Skill；涉及 `example_risk` 的查询不得由分析脚本自行实现认证或绕过该入口。
2. **菲律宾指标、EDA和透视**：优先调用 `工具/ph_data_analysis.py` 的现成函数。
3. **已有口径定义**：函数缺口才读取 `工作约定/数据口径/<国家>/` 下的指标、维度和来源表定义，并记录目标key、版本和哈希。
4. **自定义指标**：前两级都没有时才自行生成；必须记录分子、分母、成熟度、缺失处理和未复用原因。
5. **格式化Excel导出**：按组件划分职责，而非按整份工作簿的复杂度二选一。`ph_data_analysis`负责计算，`工具/excel_export.py`负责标准指标表和交叉表的最终格式；`spreadsheets` Skill及其 `@oai/artifact-tool` 工作流负责Summary、叙述和工作簿组织。复杂报告中的标准表格仍必须保留实际导出器输出，不能仅调用导出器生成中间核验件后重新绘制正式表格。

## 三、计算与导出职责

### 1. `generate_indicator`

按单个分组变量输出成交、金额、件均、占比和风险等指标。`stage='payout'`用于成交样本；下游保留函数返回的标准字段名，不另造同义字段。

### 2. `generate_pivot`

用于行维度×列维度的交叉表，`ind`为行维度，`col`为列维度，`margins=True`时保留All汇总。是否组合哪些维度由任务逻辑决定；“交叉表”指二维展示形式，不要求所有维度都两两组合。

### 3. `excel_export.merge_formatted_pivot_to_excel`

这是工作台现成的交叉表导出器。它接收 `{标题: DataFrame}`，识别多级列，写入行列维度和多级表头，保留All行/列，按指标类型设置百分比、金额、件数和风险数字格式，并对风险、占比、金额等字段添加条件格式。`merge_formatted_excel_func`是兼容别名。

### 4. `excel_export.merge_formatted_indicator_to_excel`

这是工作台现成的单维指标导出器。它写入 `{标题: DataFrame}`，处理单层或多层索引，按列名设置数字格式，对件数、金额、件均、风险和比例添加数据条，All汇总行加粗且不参与数据条计算。

### 5. 复杂模板化工作簿

当任务需要Summary概述块、支撑数据同页、多Sheet组织、特殊合并或复杂交互时，使用 `spreadsheets` Skill和 `@oai/artifact-tool` 组织外围内容并进行视觉校验，不接管标准指标表和交叉表的格式定义。

组合规则：

1. 先生成标准导出文件，再原样保留其Sheet，或连同格式导入需要的位置；支持在同一Sheet增加标题、结论和多个数据块，不强制拆页。
2. 搬移表格必须同时保留数值、数字格式、合并表头、边框、数据条和条件格式规则；行列偏移后同步移动规则范围，维持指标整块比较及All排除语义。只复制DataFrame、JSON或单元格数值再套新样式不算复用导出结果。
3. 允许按已确认展示规范调整外围标题、字体、列宽、行高和冻结窗格；不得自行取消指标标题合并、把整块条件格式拆成逐列规则，或追加未要求的阈值填充。新增样式例外须记录用户依据。
4. 组合工具不能完整保留格式时，改用能够保留标准输出的组合方式，或交付标准表格文件并说明组合限制；不得静默降级为重画。平台Skill调用边界见 `工具/README.md`，不能以工作台文档覆盖更高优先级要求。
5. 记录最终报告每个标准数据块对应的导出文件、Sheet/范围、偏移或映射。调用日志或中间核验件本身不能证明最终交付保留了导出器格式。

## 四、Excel输出与验收

1. 计算代码先输出结构化指标/透视DataFrame，并保留字段来源和口径。
2. 所有标准指标表和交叉表均用 `excel_export.py` 导出；复杂层按组合规则保留输出，不能绕过现有指标函数重新计算，也不能重绘标准格式。
3. Summary必须保留结论及支撑结论的详细数据；详细数据按分析思路编号展开。
4. 存在交叉表时，必须检查行维度、列维度、二维矩阵、多级表头和按任务要求的All行/列，并验收以下标准导出格式特征：每个指标标题跨其分箱列合并；占比类指标保留数据条；各指标的条件格式作用于整个非All数据块而非逐列独立计算；All行和All列均不进入条件格式范围。单维指标表检查标准数字格式、数据条及All排除。只验证数值或函数调用不算通过，不存在相应表格时不强加这些条件。
5. 所有Excel通用检查：概述模块是否带【】且位置正确、正文是否从下一行C列开始、详细数据与概述间隔是否为两行、标题/字体/颜色/换行/列宽/冻结窗格是否符合展示规范、来源和时间口径是否可追溯。
6. 任务特有指标、风险点、分箱数量、低频格处理和最小样本量按任务方案验收，不写成所有报告的固定指标集合。
7. 在所有组合、排版和导出步骤完成后，重新读取最终交付文件，逐块对照标准导出结果验证数值、合并区域、条件格式类型和完整范围，并抽样渲染。验收后若再次写入文件，必须重验，不能仅检查组合前的中间文件。

## 五、已知边界

- 透视聚合底表不是二维展示表。当前 `generate_indicator/generate_pivot` 将indicator列映射为明细flag，不支持任意分组后的加权底表；不能直接传入分组结果，否则可能将多笔计为一笔。分组底表按分子/分母分别求和再计算比率，或回到申请粒度使用现成函数。
- `ph_data_analysis.py`是计算层，不负责ODPS认证和最终模板版式。
- `excel_export.py`是标准结果的格式化导出层，只负责标准结果格式化导出；ODPS查询仍走 `odps-query`。
- `spreadsheets`和`@oai/artifact-tool`是平台通用工作簿能力；它们不替代业务口径、指标函数或展示规范。
