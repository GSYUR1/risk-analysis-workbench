# 工作约定：职责与必读矩阵

这里是工作台当前有效的约束集合，不是可选参考资料。每次开始先读取本文件、操作手册和安全规范，再按阶段读取矩阵中的文件。

## 单一权威与职责边界

| 文件/目录 | 维护内容 | 明确不维护 |
|---|---|---|
| `操作手册.md` | 分析事项生命周期、项目目录、命令入口和恢复方式 | 业务定义、指标算法、Excel细节 |
| `安全与审批规范.md` | 授权、审批、证据保全、敏感数据和异常运行 | 环境数值和国家指标 |
| `运行环境约定.md` | 执行环境语义、资源状态和接入边界 | 产品/客群口径和审批替代 |
| `config.json` | 工具读取的结构化配置值 | 审批证据和分析结论 |
| `数据口径接入.md` | 数据口径的定位、版本和变更治理 | 复制YAML具体条目 |
| `数据口径/<国家>/` | 国家默认样本、指标、维度和来源表定义 | 通用流程和执行环境 |
| `工具调用与分析输出.md` | 工具优先级、计算、格式化导出和验收顺序 | 脚本内部实现和任务结论 |
| `Excel分析报告展示规范.md` | Summary组织、交叉表布局和Excel视觉规则 | 项目路径和生命周期 |
| `分析归档规范.md` | 案例正文、证据、复盘和版本验收 | 分析目录初始化和运行命令 |
| `知识维护规范.md` | 从案例到候选/正式知识的晋升和去重 | 单次案例全文 |

## 必读矩阵

| 阶段 | 除操作手册、安全规范外必须读 |
|---|---|
| 制定方案或解释业务数据 | `数据口径接入.md`、对应国家《分析默认口径.md》、所需key |
| 取数、准备SQL或调整配置 | `运行环境约定.md`、当前 `config.json`、数据口径、`工具调用与分析输出.md`；按要求读取 `odps-query` Skill |
| 指标计算、EDA、透视或交叉分析 | `工具调用与分析输出.md`、`工具/README.md`、目标国家口径和所需key |
| 生成或修改Excel | `工具调用与分析输出.md`、`Excel分析报告展示规范.md`、已确认口径；按要求读取 `spreadsheets` Skill |
| 复盘与归档 | `分析归档规范.md`、原始结论和证据 |
| 知识或模板维护 | `知识维护规范.md`、相关正式条目和来源案例 |
| 工作台维护 | 本职责表、受影响文档、工具和离线测试 |

“必读矩阵”就是本节的阶段路由表。它是纲领性入口，告诉Agent拿到任务后按阶段加载哪些权威文件；它不另存一份隐藏配置，也不复制各文件正文。

## 冲突处理

用户当前明确指令优先，其次是同职责的现行权威文件，再次是已确认的任务例外。历史快照、运行日志和模板占位值不能升级为当前规则。机器配置与文字不一致时标记待核对，不为了文案整齐擅自改值或扩大权限。

## 历史材料

`接入检查/`、`历史记录/` 和已归档案例中的旧文件只用于追溯，不是当前必读入口。当前规则只认本目录现行文件及其明确引用的国家口径文件。
