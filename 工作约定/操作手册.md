# 操作手册

本文件统一维护如何开展分析：事项身份、文件位置、生命周期和命令入口。授权与敏感数据边界见《安全与审批规范》；指标、展示和复盘按《工作约定/README.md》的必读矩阵加载。

## 1. 识别项目与事项

当前打开的业务项目是项目根目录；`analysis_id`标识分析事项，`thread_id`标识对话窗口。先查项目 `risk-analysis/analysis-index.json`；继续同一业务目标只关联窗口，不因日期、分箱修订或补充分析重复立项。独立业务目标才新建分析事项。

## 2. 分析目录

- 项目根目录的 `risk-analysis/` 只放项目索引和分析目录。
- `init-project`生成项目、分析和窗口索引；`new-analysis`创建独立分析目录并返回路径。
- 不预建空产物目录；文件按实际阶段创建。

| 位置 | 内容及创建时机 |
|---|---|
| `analysis.json` | 事项标识、目标、状态、窗口和路径 |
| `plan.json` | 方案确认后保存样本、指标、来源、假设和验收项 |
| `sources/` | 输入来源引用；大文件优先只保存引用 |
| `sql/` | 首次保存SQL |
| `scripts/`、`notebooks/` | 首次保存对应代码 |
| `runs/<run_id>/` | 有执行时记录请求、结果、日志和状态 |
| `artifacts/` | 必要的中间产物 |
| `artifacts/bases/<base_id>/` | 同一批交叉表共用的可复算底表、SQL副本、数据口径清单及补表脚本；首次计算交叉表前保存 |
| `deliverables/` | 对用户交付的报告或Excel |
| `review/` | 复盘正文和归档草稿 |
| `history/` | 必要的版本历史 |

工作台规则和工具变更历史集中放 `历史记录/工作台维护/`；不把维护快照混入分析目录。

## 3. 分析流程

```powershell
$cli = '.\工具\workbench.py'
python -X utf8 $cli init-project --project-root .
python -X utf8 $cli new-analysis --project-root . --spec '已填写的analysis.json' --thread-id THREAD_ID
python -X utf8 $cli link-thread --project-root . --analysis-id ANA-具体编号 --thread-id THREAD_ID
```

1. 从 `分析模板/analysis.json`填写立项输入；国家和产品默认值读数据口径，不照抄空值。
2. 在分析目录保存 `plan.json`：目标、样本、时间窗、指标分母和成熟度、来源版本、假设、混杂、资源、保留和验收标准。用户确认后再执行。
3. 按必读矩阵加载环境、口径和工具；保存SQL/代码及审批依据后，使用已支持且获批的执行路径。
4. 进入指标、EDA、透视或报告阶段时，按《工具调用与分析输出》选择计算和导出工具；同底数交叉表先保存共用底表数据包，再生成报告。补充交叉先加载原数据包，不默认重跑取数。不要直接用临时脚本替代已有指标或格式化导出器。
5. 交付前分别做业务口径、数值、结构、视觉和任务特有指标验收；复盘先形成草稿，用户确认后归档。

## 4. 归档与检索

```powershell
python -X utf8 $cli archive-draft --project-root . --analysis-id ANA-具体编号 --spec '已填写的archive.json'
python -X utf8 $cli finalize-archive --project-root . --analysis-id ANA-具体编号 --reviewer '实际审核人' --evidence '真实确认及出处'
python -X utf8 $cli search-projects --query '业务关键词'
```

当前事项归档在分析目录的 `review/`，正式案例复制到 `项目归档/<项目>/analyses/<analysis_id>/`；大型源文件不复制。归档不等于数据库执行关闭，也不等于策略收益验证。

## 5. 恢复与维护

恢复先读项目索引、事项JSON和对应产物；索引只是发现入口，不是分析结论。补充分析先查原报告运行记录中的base_id及其manifest；底表位于远程时在原环境运行补表，只回传获批汇总。项目现场保留底表，工作台归档只保存路径、摘要和哈希，不复制客户明细。工具改动后运行工作台离线测试，测试只使用合成数据和临时目录；不连接真实ODPS、SSH或DSW，不自动提交Git。
