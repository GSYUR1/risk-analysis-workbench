# 分析输入模板

只存可复用的空白结构，不能存真实项目状态或结果。

- `analysis.json`：分析事项立项输入；填好后交 `new-analysis`，国家和产品按已确认数据口径填写。
- `archive.json`：归档元数据输入；填好后交 `archive-draft`。正文必须满足分析归档规范，不能只填几个字段就宣称复盘完成。
- `base_contract.grouped.json`：共用聚合底表的数据口径输入示例，按当前分析完整填写字段和指标，不将示例当作默认指标全集；保存和补表操作见`工具/analysis_base使用说明.md`。

一次性立项草稿和历史接口输入不再保留在当前模板目录；如需追溯，查历史记录或项目案例。
